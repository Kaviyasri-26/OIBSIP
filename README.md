## Objective

Research and explain common network security threats, how they work, their real-world impact, and practical mitigation strategies.

## Threats Covered

This report covers:

1. DoS/DDoS Attacks
2. Man-in-the-Middle (MITM) Attacks
3. IP Spoofing
4. DNS Poisoning/Spoofing

It also includes:

- Real-world examples
- Impact of each threat
- Three mitigation strategies for each threat
- Comparison table
- General prevention practices
- Conclusion with three key takeaways
- Credible security references
